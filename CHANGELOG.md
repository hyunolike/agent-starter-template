# Changelog

## 0.1.0 — 2026-10-14

Initial starter implementation:

- FastAPI service with a bounded LangGraph tool loop.
- Deterministic demo mode and an optional Anthropic adapter.
- Three typed, read-only tools backed by fictional data.
- Async SQLite checkpoints, thread inspection, and resume.
- Execution limits, shared-token auth, structured logs, tests, and demo evaluations.
- Locked Python dependencies, Docker, CI, and linked English/Korean documentation.
